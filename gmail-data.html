PRODUCT UPDATE

AI Cleanup does not access Gmail

The current app focuses on photo, video, compression and memory cleanup on iPhone.

AI Cleanup does not connect to Gmail, request Google OAuth access or access Google user data. The old Gmail cleanup description is no longer applicable to the current app.

CURRENT FEATURES

What AI Cleanup does

  • Review photos and videos for cleanup.
  • Compress selected large photos and videos.
  • Optimize available iPhone memory through the app's cleanup tools.
  • Keep cleanup actions user-confirmed.
