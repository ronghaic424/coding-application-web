# CODING APPLICATION static website

This directory contains the public website for CODING APPLICATION and its mobile products. It is written in plain HTML and CSS for static hosting.

No package installation, Node.js server, database or build command is required. Open `index.html` directly in a browser or upload this directory to a static web host.

## Pages

- `index.html` — product directory for MultiSpace, AI Cleanup, Audio Editor and Timestamp Camera Basic+
- `home.html` — AI Cleanup product page
- `aicleanup-privacy.html` — AI Cleanup privacy policy
- `terms.html` — AI Cleanup terms of use
- `support.html` — AI Cleanup support
- `audio_editor_home.html` — Audio Editor product page
- `timestamp_camera_home.html` — Timestamp Camera Basic+ product page
- `public/` — app icons, favicon and social image

AI Cleanup currently focuses on photo and video cleanup, compression cleanup and iPhone memory optimization. It does not connect to Gmail or access Google user data.
